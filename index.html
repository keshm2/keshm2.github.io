01about

I'm a senior Informatics student at the University of Washington, minoring in Data Science, focused on cloud infrastructure, network engineering, and cybersecurity, plus backend, QA, IT/systems, and a bit of frontend on the security side.

Most of what I build starts from something I actually wanted, not a tutorial I followed. I got tired of copy-pasting the same resume into every application, so I built aplyx. It runs on top of whatever coding agent I already have open, applies to postings on its own, and pings me on Discord when one goes through. I wanted to ask questions about my own PDFs instead of scrolling through them, so I built Kyper one weekend messing around with Llama 3 and embeddings. ben, a Discord bot, handles chore reminders for about 50 students now, and HusKey Manager, a password vault I built for UW's INFO 310 cybersecurity course, exists mostly because I wanted to see, hands-on, how authentication and access control actually break.

I also help run the technical side of UW's Kappa Theta Pi chapter, which is where UW KTP below came from.

Before I was making these tools, I was the user hoping one already existed.

02featured work

aplyx

active

A local-first job application agent that runs on top of a coding agent you already have installed (opencode or Claude Code get full capability). It searches boards like Ashby, Lever, Greenhouse, and Workday, skips anything already seen, tailors a resume and cover letter per posting, applies, pings Discord with the outcome, and logs every success to a Google Sheet. aplyx is the workflow; the agent is the executor.

UW KTP

active

The chapter-management platform for Kappa Theta Pi's UW chapter, recently transferred into the chapter's own GitHub org to become its actual system of record. A public rush site, a member portal, and an admin console, with the goal of automating due collection through Stripe (or another processor), tracking attendance to push it up, budgeting the year automatically from what actually gets collected, and keeping member points and absences in one place instead of a spreadsheet. Currently a working front-end demo with mock data and a Stripe-style mock checkout. The real backend is next.
